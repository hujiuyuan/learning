# 一、模型和损失

## 什么是线性回归

线性回归是一种监督学习算法，用于预测连续值。假设输入特征和输出之间存在近似线性关系。

### 一元线性回归

$$\hat y = wx + b$$

### 多元线性回归

$$\hat y = w_1x_1 + w_2x_2 + \cdots + w_n x_n + b = \mathbf{w}^T\mathbf{x} + b = \sum^n_{i=1}w_ix_i +b$$

常用损失函数是**均方误差 MSE**：

$$J(w,b) = \frac {1}{2n} \sum^n_{i=1}(\hat y_i - y_i)^2$$

三个动作：**相减 → 平方 → 加起来除以 2n**。`**2` 是逐格平方，`.sum()` 是全部加起来。

## 什么是梯度下降

梯度下降是一种**优化算法**，用来最小化损失函数。它不限于线性回归，也广泛用于逻辑回归、神经网络等模型。

直观理解：你站在一座山上，想走到山谷最低点。你环顾四周，找到当前最陡的下坡方向，然后朝那个方向走一小步；重复这个过程，最终到达谷底。

数学上，梯度表示函数上升最快的方向，所以**负梯度方向就是下降最快的方向**：

$$\theta := \theta - \alpha \nabla J(\theta)$$

### 更新式从哪来

不是约定，也不是定理，是最简单的「沿最速下降方向走一小步」：

1. 当前在 `w`，走一小步 `Δ`，一阶近似：`J(w+Δ) ≈ J(w) + grad(w)·Δ`。
2. 要让 `J` 变小，需要 `grad·Δ < 0`，所以 `Δ` 与 `grad` 反号。
3. 取 `Δ = -lr·grad(w)`，则 `J(w+Δ) ≈ J(w) - lr·grad² ≤ J(w)`。
4. 于是 `w_new = w - lr·grad(w)`。

`lr` 是步子大小。步子太大，一阶近似不成立，才会震荡或发散。

对 `J(w)=(w-2)²`，`grad=2(w-2)`。令 `e=w-2`，更新后：

```
e_new = e·(1-2lr)
```

这个倍率决定行为：

| lr | 倍率 1-2lr | 行为 |
| --- | --- | --- |
| 0.01 | 0.98 | 每步只缩小 2%，很慢 |
| 0.1 | 0.8 | 每步缩小 20%，收敛 |
| 1.0 | -1 | 距离不变、方向反转，来回跳 |
| 1.1 | -1.2 | 距离每步放大 20%，发散 |

# 二、用 numpy 跑一遍

## 例 1 前向：`y = X @ w + b`

```python
import numpy as np

X = np.array([[1., 2.],
              [2., 1.],
              [3., 4.],
              [4., 3.]])      # 4 个样本，每个 2 个特征   (4, 2)
w = np.array([[2.],
              [3.]])          # 2 个权重，竖着写          (2, 1)
b = 1.0                       # 偏置，一个数，0 维       ()

y = X @ w + b                 # (4,2) @ (2,1) -> (4,1)，再加标量
print(y.shape, '\n', y)
```

```
(4, 1)
[[ 9.]
 [ 8.]
 [19.]
 [18.]]
```

**第一个样本 `[1, 2]` 手算**：`1*2 + 2*3 = 8`，再 `+1` → **9**。

三个数各自的位置，别搞混：

| 东西 | 值 | 作用 |
| --- | --- | --- |
| `@` | `X @ w` | 一行 · 一列 → **一个数**（先把 2 个特征加总） |
| `+ b` | `+ 1.0` | 整个结果加一次，广播到每一行 |
| 结果 | `(4, 1)` | 4 个样本，一个样本一个预测值 |

## 例 2 损失：MSE

```python
y_true = np.array([[9.], [8.], [19.], [20.]])

err = y - y_true                  # [[0], [0], [0], [-2]]
J = (err ** 2).sum() / (2 * 4)    # (0+0+0+4) / 8
print(err.ravel(), J)             # [ 0.  0.  0. -2.] 0.5
```

`2 * 4` 里的 4 是**样本数**，`4/8 = 0.5`。

## 例 3 训练：单特征、单权重

单特征时梯度有现成式子（`n` 是样本数）：

$$\frac{\partial J}{\partial w} = \frac{1}{n}\sum(\hat y_i - y_i)\,x_i$$

**一句话版本**：每个样本的（预测减真实）乘上它自己的 `x`，加起来除以样本数。

```python
import numpy as np

x = np.array([1., 2.])
y = np.array([2., 4.])

w = 3.0        # 从 3 出发（真实关系是 y = 2x，所以答案应该是 2）
alpha = 0.1    # 学习率

for step in range(20):
    err = w * x - y
    J = (err ** 2).sum() / (2 * 2)     # 2n，n=2
    grad = (err * x).sum() / 2          # n，n=2
    w = w - alpha * grad                # 先更新，再打印
    print(f'step {step:>2}  w = {w:.4f}  J = {J:.4f}')
```

```
step  0  w = 2.7500  J = 1.2500
step  1  w = 2.5625  J = 0.7031
step  2  w = 2.4219  J = 0.3955
step  3  w = 2.3164  J = 0.2225
...
step 19  w = 2.0032  J = 0.0000
```

`w`：从 3 出发，第 1 步 2.7500，第 20 步 **2.0032**（真实关系是 `y = 2x`，答案就是 2）；`J`：1.25 → … → **0.0000**。

> ⚠️ **同一行里 `w` 和 `J` 不是同一个 `w` 算的**：`J` 用的是更新**前**的 `w`，`w` 打印的时候已经更新完了。所以 step 0 那行是「`w=3` 时的损失 1.25」+「更新后的 w=2.75」。见坑表最后一条。

**梯度方向不用试数字，看误差的正负**：

- `ŷ - y` 是**正** → 猜大了 → 推 `w` 变小
- `ŷ - y` 是**负** → 猜小了 → 推 `w` 变大
- 再乘 `x` 只是票的权重：`x` 大的样本，`w` 变一点它的预测变得更多，说话更管用

**那个 `1/2` 是留给求导的**：平方求导掉出一个 `2`，正好被 `1/2` 约掉，最后只剩 `(ŷ-y)·x`。

**为什么步子越来越小**：每走一步都更靠近谷底，误差变小、梯度也变小，所以挪的距离自然变短（0.25 → 0.19 → …）。不会冲过头。

## 例 3.5 学习率实测

`J(w)=(w-2)²`，起点 `w=10`，各跑 10 步：

| lr | 10 步后 w | 10 步后 J | 行为 |
| --- | --- | --- | --- |
| 0.01 | 8.5366 | 42.7269 | 几乎不动 |
| 0.1 | 2.8590 | 0.7379 | 明显靠近 |
| 1.0 | 10 / -6 交替 | 64 | 来回跳 |
| 1.1 | 51.5339 | 2453.6064 | 越跳越远 |

**为什么**：`e_new = e·(1-2lr)`。`lr=1.0` 时乘 `-1`，距离不变、方向反转；`lr=1.1` 时乘 `-1.2`，每步放大 20%。

**J 变小代表什么**：`J` 是误差，变小代表模型更接近正确答案。训练就是重复「算 J → 算梯度 → 调 w」，直到 `J` 不再明显下降。

## 例 3.6 多特征梯度：dW、db

`err = X@w + b - y`，`n` 是样本数，`m` 是特征数。

```
J = (err**2).sum() / (2n)
dW = (X.T @ err) / n     # (m,n) @ (n,1) -> (m,1)
db = err.mean()          # 标量
```

为什么是 `X.T @ err`：`X.T` 的每一行是 `X` 的一列（一个特征在所有样本上的值），和 `err` 逐项相乘再求和，就是那个特征的梯度。`@` 是行·列点积再求和；`*` 是逐元素乘，形状会变成 `(m,n)`，不要混。

具体数：

```
X = [[1,0],[0,1],[1,1],[2,1]]   # 4 个样本，2 个特征
w = [[1],[1]]
b = 0.5
y = [[2.5],[2.5],[3.5],[4.5]]

ŷ = [[1.5],[1.5],[2.5],[3.5]]
err = [[-1],[-1],[-1],[-1]]
J = 4/(2×4) = 0.5

X.T = [[1,0,1,2],
       [0,1,1,1]]              # (2,4)

X.T @ err = [[-4],
             [-3]]             # (2,1)

dW = [[-1],
      [-0.75]]
db = -1
```

更新：`w = w - lr*dW`；`b = b - lr*db`。

**这里最容易错**：把 `X.T @ err` 算成 `X.T * err`（逐元素乘），得到 `(2,4)`；`@` 后才是 `(2,1)`。

## 例 4 形状对照表（写代码前先查这个）

| 东西 | 怎么写 | shape |
| --- | --- | --- |
| 一批样本 | `X = np.ones((100, 3))` | `(100, 3)` |
| 权重（3 个特征 3 个权重） | `w = np.ones((3, 1))` | `(3, 1)` |
| 偏置 | `b = 1.0` | `()` 一个数 |
| 预测 | `X @ w + b` | `(100, 1)` |
| 误差 | `y - y_true` | `(100, 1)` |
| 损失 | `(err ** 2).sum() / (2 * 100)` | `()` 一个数 |

`(100,3) @ (3,1)`：中间那个 3 相等 → 能乘；结果取最左 100、最右 1 → `(100,1)`。`b` 是 0 维，能广播到任何形状。

**`w` 写成 `(3,)` 也能算**，但结果是 `(100,)`，后面跟别的数组相乘时形状就会对不上。模型里统一竖着写 `(3, 1)`。

# 三、踩过的坑

| 坑 | 正解 |
| --- | --- |
| `X @ w` 算成「每个权重各配一个 b」，写成 `2*1+1`、`3*2+1` | 一行 · 一列 = **一个数**，先加总再加 `b` |
| 以为 `b` 要给每个权重各加一次 | `b` 整个结果只加一次，广播到每个样本 |
| 把 `(5,)` 当竖着的一列 | `(5,)` 没有行也没有列；要竖着写 `(5,1)` |
| `J` 里的 `2n` 只写了 `n` | `J` 除以 `2n`，梯度才除以 `n`（那个 2 被约掉了） |
| 以为「打印的 `J` 和 `w` 是同一组参数」 | 脚本里 `J` 用旧 `w` 算、`w` 已更新，两者差一步 |
| 把目标 `w` 当成第一步走到的 `w` | 目标是 `grad=0` 的 `w`；一步后的 `w` 只是路上的一点 |
| 看到 `J` 变小但不知道代表什么 | `J` 是误差；变小代表模型更接近正确答案，训练就是重复到它不再降 |

# 五、这次卡住的点（11-06）

1. **符号一多就对不上**：`x`、`w`、`b`、`y_hat`、`err`、`J`、`dJ/dw`、`dJ/db` 混在一起时，忘了每个符号对应什么。先看 [[符号字典]] 的「线性回归这一阶段」表，再做题。
2. **漏 `b`**：算 `y_hat` 时只算 `w*x`，忘了加 `b`（m22）。
3. **`@` 当成逐元素乘**：`X.T@err` 写成 `X.T*err`，形状从 `(2,1)` 变成 `(2,4)`（m23）。
4. **模型从哪来**：`y=wx+b` 不是从数字推出来的。题目说「每增加 1 个单位，结果增加 `k`」→ `w=k`；说「固定加一笔 / 基础价」→ `b`。没有这两个条件，就不要硬套线性模型。

下次重来：只做一个样本、只调 `w`、`b` 固定 0，四步只报数：`y_hat`、`err`、`dJ/dw`、`w_new`；确认后再加 `b`，最后才到多特征。
