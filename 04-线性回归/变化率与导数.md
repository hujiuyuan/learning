## 1. 变化率 = 结果的变化 ÷ 原因的变化

别记成「变化量 ÷ 变化量」—— 两个词一样，等于没说。

| | 是什么 | 单位 |
| --- | --- | --- |
| **分子** | 结果变了多少 | 米 |
| **分母** | 原因变了多少 | 秒 |

因为**时间**走了，所以**位置**跟着走 → 时间是原因，放下面。

验一下这个判断：3 天花了 60 块 → `60 ÷ 3 = 20 块/天`。反过来写 `3 ÷ 60` 就成了「每块钱花了多少天」，单位都不对。**分母永远是「因为什么变」的那个量。**

## 2. 数值做法：把区间缩短

```python
def s(t):
    return t * t

for h in (1, 0.1, 0.01, 0.001):
    print(h, (s(2 + h) - s(2)) / h)
```

```
1     5.0
0.1   4.100000000000001
0.01  4.009999999999891
0.001 4.000999999999699
```

区间越短，数越往 **4** 靠。这个 4 就是 `t = 2` 那一刻的速度，也就是 `s = t²` 在 `t = 2` 处的**导数**。

换成 `t = 3`：`7.0 / 6.1 / 6.01 / 6.001` → 往 **6** 靠。
换成 `t = 4`：往 **8** 靠。

于是 `t` 和速度的关系是 `速度 = 2t`。

## 3. 记号

| 写法 | 读作 | 是 |
| --- | --- | --- |
| `(t²)'` | t² 的导数 | 一个**函数**：每个 t 对应一个变化率 |
| `t = 1 时的导数` | — | 一个**数**：把 t 代进去算出来的 |

「求导」是动作（把原函数变成变化率函数），「导数」是结果。

## 4. 自己推出来的三辆车

| 位置 `s(t)` | 速度 | 怎么来的 |
| --- | --- | --- |
| `t²` | `2t` | t=2→4、t=3→6、t=4→8 |
| `3t² + 2t + 5` | `6t + 2` | 四个点 `8.003 / 14.003 / 20.003 / 26.003`，每步涨 6、起点补 2 |
| `5t²` | `10t` | t=2 时 20，系数从 3 换成 5，斜率跟着从 6 变成 10 |

**抓的是「系数乘 2」，不是记住 6 和 10。** 这是规律，不是记忆。

`5t²` 那组输出里每行多出来的 `0.005`，是 `5h` 没消掉的残渣 —— h 越小它越小。

## 5. 规则（都是结论，不是前提）

```
x 的 n 次方  →  n × x 的 (n-1) 次方     指数搬下来当系数，指数减 1
常数          →  0                       不变的东西，变化率是 0
前面有系数    →  系数照搬                5t² → 5 × 2t = 10t
几项相加      →  一项一项分别求，再连起来
```

## 6. 踩过的坑：整段的平均 ≠ 那一刻

问 `t = 3` 的速度时答了 **5**。来源是 `h = 1` 那一行：从 2 秒走到 3 秒，`(9-4)/1 = 5`。

这个 5 没错，但它是**「2 到 3 这一整段」的平均**。那一段里速度从 4 涨到 6，平均值正好落在中间。

```
2 秒时      4
3 秒时      6
整段平均    5     ← 不是那一刻
```

问「那一刻」，就要把区间缩到 0 附近去逼近。

## 7. 和后面的关系

梯度下降里那个「梯度」，就是**导数**。

调 `w` 时靠误差的正负判断方向，那是人肉版；有了导数就能直接算出「该往哪挪、挪多快」。第 8 节用上。
