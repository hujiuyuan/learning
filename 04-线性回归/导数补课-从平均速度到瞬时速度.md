## 1. 术语（只用学术名词）

| 术语 | 记号 | 定义 |
| --- | --- | --- |
| 函数值 | `f(t)`、`u(0)` | 把数代进去算出来的那个值 |
| 平均变化率 | `Δf/Δt = (f(t+h) − f(t)) / h` | 一段区间内，函数平均变多快 |
| 导数（瞬时变化率） | `f'(t)`、`ds/dt` | 上面那个式子令 `h → 0` 的极限 |
| 斜率 | 同上 | 导数的几何叫法：切线的倾斜程度 |

**别自己造词。** 教学中用过的「高度 / 陡度」是自造口语，跟别人交流时对不上号，已作废。

## 2. 平均变化率 = 结果的变化 ÷ 原因的变化

- `t = 2` 秒时位置 6 米，`t = 5` 秒时位置 21 米 → `(21 − 6) ÷ (5 − 2) = 5` 米/秒
- 分母永远是「因为什么变」的那个量（这里是时间）。

## 3. 缩区间：从平均逼近瞬时

`s = 3t²`，在 `t = 2` 附近：

| 时刻 | 位置 | 这一段平均速度 |
| --- | --- | --- |
| 2.1 | 13.23 | 12.3 |
| 2.01 | 12.1203 | 12.03 |
| 2.001 | 12.012003 | 12.003 |

→ 撞向 **12**。这就是 `t = 2` 处的导数。

另一个：`(2t+5)²` 在 `t = 0`：

| h | 平均变化率 |
| --- | --- |
| 0.1 | 20.4 |
| 0.01 | 20.04 |
| 0.001 | 20.004 |

→ **20**。

## 4. 残渣（截断误差）

多出来的部分不是算错，是 `h` 没缩到 0 留下的残渣，正式名字叫**截断误差**：

```
12.3   = 12 + 3 × 0.1
12.03  = 12 + 3 × 0.01
12.003 = 12 + 3 × 0.001
20.004 = 20 + 4 × 0.001
```

h 缩 10 倍，残渣也缩 10 倍；h → 0，残渣 → 0。

## 5. 自己量出来的规则

| 位置 | 导数（速度） | 怎么来的 |
| --- | --- | --- |
| `5t²` | `10t` | t=2→20、t=3→30、t=4→40、t=5→50 |
| `4t²` | `8t` | 系数 4 翻倍 |
| `3t²` | `6t` | 系数 3 翻倍 |
| `6t²` | `12t` | 系数 6 翻倍；t=5 时 60 |

**抓的是「系数乘 2」，不是记数字。**

## 6. 两层：相乘，不是相加

- 第一级：`t` 走 1 → `u` 走 3
- 第二级：在 `u = 2` 那儿，`u` 走 1 → `s` 走 4
- 合起来：`t` 走 1 → `s` 走 `3 × 4 = 12`

硬算验证：`t` 从 0 走到 0.001，`u` 从 2 到 2.003，`s` 从 4 到 `4.012009`，涨幅 `0.012009 ÷ 0.001 = 12.009` → 贴着 12。多出来的 `0.009` 还是残渣（`9 × h`）。

## 6.1 外层导数在哪一点取（这次真正卡住的地方）

链式法则写成：

```
dh/dt = dh/du × du/dt
```

`dh/du` 是**外层函数**的变化率，必须把**内层算出来的 `u`** 代进去，不能把 `t` 代进去。

以 `h=(3t+2)²` 在 `t=1` 为例：

```
u = 3×1 + 2 = 5
du/dt = 3                 # 内层：t 每变 1，u 变 3
dh/du = 2u = 2×5 = 10     # 外层：在 u=5 处，u 每变 1，h 变 10
dh/dt = 10 × 3 = 30
```

数值验证：`h(1)=25`，`h(1.001)=25.030009`，`(25.030009−25)÷0.001≈30.009`，贴着 30。

**错法**：把 `t=1` 代进 `2u`，得到 `2×1=2`，再乘 `3` 得 `6`；或者只算到 `dh/du=10` 就停。两种都漏了「外层用 `u` 的值」。

为什么不能代 `t`：`dh/du` 的单位是「`h` 的变化 ÷ 每个 `u`」，它只认 `u`；`t` 的单位是时间，两者不是同一个量。就像「1 美元换 150 日元」只能乘美元数，不能乘人民币数。

固定三行：

```
u = 内层在 t 这一点的值
dh/du = 外层在 u 这一点的导数
dh/dt = dh/du × du/dt
```

## 6.2 什么时候不能用：尖点没有导数

链式法则要求每一层在对应点有导数。尖点没有唯一的导数，所以那一步不能乘。

`h=|u|` 在 `u=0`：

| 从哪边靠近 | 变化率 |
| --- | --- |
| 左边 | `(0 − 0.001) ÷ 0.001 = -1` |
| 右边 | `(0.001 − 0) ÷ 0.001 = +1` |

左右两边给的变化率不同，`u=0` 这一点没有唯一的导数。类似地，除以 0、根号里是负数——那一层在那个点没有定义，也谈不上导数。

三层以上：`y` 依赖 `v`，`v` 依赖 `u`，`u` 依赖 `t`，就乘三次：

```
dy/dt = dy/dv × dv/du × du/dt
```

少乘一层，链条就断在半路。

## 7. 踩过的坑

1. **`(2t+5)²` 在 `t=0` 答 125**：把函数值 `25` 又乘了 5。函数值是「多高」，导数是「多快」，两回事。
2. **两层题答 21**：那是 `t` 从 0 到 1 **整段**的平均（`(25 − 4) ÷ 1`），不是那一刻。把步长换成 0.001，就不会走满一整秒。
3. **小数点点错**：`4.012009 − 4` 写成 `0.12009`（应为 `0.012009`），结果差 10 倍。
4. **`t²` 在 `t=3` 答 5**（10-22）：`h = 1` 那一行是 2 到 3 的整段平均，不是那一刻。

6. 为什么 `h=|u|` 在 `u=0` 不能用链式法则？

<summary>答案</summary>

5. `u=5`，`du/dt=2`，`dh/du=3u²=75`，`dh/dt=75×2=150`
6. 从左边靠近变化率是 `-1`，从右边是 `+1`，没有唯一的导数，链式法则缺一个可乘的数。
