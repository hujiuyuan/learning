# Part 1 重新学习

## 规则 1：形状是一个元组，整体传进去

```python
shape = (3, 4)        # 形状本身就是一个元组
np.zeros(shape)       # ✓ 把整个元组传进去
np.zeros((3, 4))      # ✓ 同上：调用的 () 和元组的 () 挨在一起
np.zeros(3, 4)        # ✗ TypeError: Cannot interpret '4' as a data type
```

`np.zeros(3, 4)` 里的第二个位置是 `dtype`，不是「第二维」。所有带 shape 参数的函数（`zeros` `ones` `arange` 以外的 `reshape` `empty`）都是这个规矩，`reshape` 例外 —— 它两种写法都收：`a.reshape(3, 4)` ✓、`a.reshape((3, 4))` ✓。

**怎么验**：`type((3,4))` → `tuple`；`type((3))` → `int`。

## 规则 2：形状怎么写、怎么念

**shape 里有几个数字，就是几维；每个数字，就是那一维多长。**

| 形状 | 几维 | 怎么念 | 打印长什么样 |
| --- | --- | --- | --- |
| `()` | 0 维 | 一个裸数字 | `7` |
| `(4,)` | 1 维 | 4 个元素的**一条线**，没有行也没有列 | `[7 8 9 10]` |
| `(4, 1)` | 2 维 | 4 行 1 列 | `[[7] [8] [9] [10]]`（竖着） |
| `(2, 3, 4)` | 3 维 | 2 层，每层 3 行 4 列 | 一串 `[[[ ... ]]]` |

一维那个**尾逗号是 Python 元组的语法**，不是 numpy 的：

```python
type((4,))   # tuple  ← 带逗号才是元组
type((4))    # int    ← 不带逗号，只是给 4 加了个括号
```

**反例**：写成 `(4)` 当下标用没问题，但**它不能当形状传**。写形状时，一维必须有逗号。

## 规则 3：下标 —— 一对方括号 + 逗号；整数挤掉、冒号留着

```python
c = np.arange(12).reshape(3, 4)

c[1, 2]        # 6        ← 第 1 行第 2 列，一个数，0 维
c[1, :]        # [4 5 6 7]      (4,)    逗号后面是全切片 → 行被消掉，只剩列
c[1:2, :]      # [[4 5 6 7]]    (1, 4)  冒号 → 行留着
c[:, 2]        # [2 6 10]       (3,)    列被消掉
c[:, 2:3]      # [[2] [6] [10]] (3, 1)  列留着
```

**口诀：每一格里出现冒号 `:`，那一维就留着；是整数，那一维就消失。** 剩下的轴按原顺序组成结果的形状。

**最阴的一条：单个元素时两种写法一样，切片时才分家。**

```python
c[1, 2]        # 6
c[1][2]        # 6          ← 一样，所以发现不了问题

c[0:2, 1]      # [1 5]      (2,)   前两行的第 1 列
c[0:2][1]      # [4 5 6 7]  (4,)   前两行里的第 1 行 —— 完全不是一回事
```

写 numpy 下标**只用一个方括号**，多个位置用逗号隔开。`c[1][2]` 是 Java 的习惯，别用。

## 规则 4：广播 —— 从右往左对齐，缺的位补 1

两步：

1. **对齐**：从右往左一位一位比，短的数组左边补 `1`。
2. **逐位检查**：每一位要么相等，要么其中一个是 `1`。全过 → 按较大的那个取长度；有一处不过 → `ValueError`。

```python
a = np.ones((4, 5))

a + np.ones((5,))     # ✓ (4, 5)   (5,) 补成 (1,5)，列 5 对 5，行 1 可以铺成 4
a + np.ones((4, 1))   # ✓ (4, 5)   行 4 对 4，列 1 可以铺成 5
a + np.ones((5, 1))   # ✗ ValueError: shapes (4,5) (5,1)
```

**`(5,)` 不是「竖着的一列」** —— 这是 md 里 m17 那条错的根。它是一维，只有一位，补位后是 `(1, 5)`，所以它占的是**列方向**。想要「一列」，得写成 `(5, 1)`，补位后是 `(5, 1)`，占的是**行方向**。

| | `(5,)` | `(5,1)` |
| --- | --- | --- |
| 维数 | 1 维 | 2 维 |
| 补位后 | `(1,5)` | `(5,1)` |
| 配 `(4,5)` | ✓ 配列 | ✗ 5 配行，行只有 4 |

## 规则 5：`@` —— 中间位相等，每格 = 左一行 · 右一列

```python
np.ones((5, 3)) @ np.ones((3, 2))   # ✓ (5, 2)：中间 3 = 3；结果取最左 5 + 最右 2
np.ones((5, 3)) @ np.ones((2, 3))   # ✗ ValueError: matmul: ... mismatch in its core dimension
```

中间位就是**左边最后一个数**和**右边第一个数**，必须相等。结果形状 = 左边去掉中间位 + 右边去掉中间位：

```
(5, 3) @ (3, 2)  →  (5, 2)
  ↑     ↑   ↑        ↑    ↑
 行    中间   行
```

一维参与时那一维会被吃掉：

```python
np.ones((3, 4)) @ np.ones((4,))   # (3,)   左边留 3，右边的 4 被吃掉
np.ones((4,)) @ np.ones((3, 4))   # (3,)   右边留 3，左边的 4 被吃掉
np.ones((4,)) @ np.ones((4,))     # ()     0 维，就是一个数（点积）
```

## 形状速查（贴在手边）

| 你想要 | 写什么 | shape |
| --- | --- | --- |
| 一条线 | `np.array([1,2,3,4])` | `(4,)` |
| 竖着的一列 | `np.array([[1],[2],[3],[4]])` 或 `a.reshape(4,1)` | `(4,1)` |
| 一行 | `a.reshape(1,4)` | `(1,4)` |
| 全 0 的 3 行 4 列 | `np.zeros((3,4))` | `(3,4)` |
| 取第 i 行 | `a[i, :]` | 少一维 |
| 取第 j 列 | `a[:, j]` | 少一维 |
| 取第 j 列但保持二维 | `a[:, j:j+1]` | 列维留 1 |
