## 1. 形状：从外往里数

**`shape` 就是“每一重方括号里有几个东西”，从外往里数。**

```python
b = np.arange(12).reshape(3, 4)

len(b)      # 3   最外面那重括号里有 3 个
len(b[0])   # 4   里面那重有 4 个
b.shape     # (3, 4)
```

```python
e = np.arange(24).reshape(2, 3, 4)

len(e)         # 2
len(e[0])      # 3
len(e[0][0])   # 4
e.shape        # (2, 3, 4)
```

一句话等价式：`b.shape == (len(b), len(b[0]))`，每往里一重就多 `len()` 一次。

**术语只留一个**：说「第 1 重括号、第 2 重括号」。不再混用“维 / 轴 / 壳 / 层”——那几个词指同一件事，换着说只会让人更糊涂（见 [[numpy错误试探记录]] 第四节）。

## 2. 切片：冒号留、整数消

下标里每个位置管一重括号：

- 写**整数** → 那一重括号**没了**，只留下那个位置的东西
- 写**冒号** → 那一重括号**留着**，长度按取到几个**重数一遍**

```python
b = np.arange(12).reshape(3, 4)

b[1]        # [4 5 6 7]         (4,)   第 1 重没了
b[1:2]      # [[4 5 6 7]]       (1,4)  第 1 重留着，里面只剩 1 行
b[:, 2]     # [2 6 10]          (3,)   第 2 重没了
b[:, 2:3]   # [[2] [6] [10]]    (3,1)  第 2 重留着，里面只剩 1 列
```

三维同理：

```python
e = np.arange(24).reshape(2, 3, 4)

e[0]          # (3, 4)     第 1 重没了
e[:, 1, :]    # (2, 4)     只有第 2 重没了
e[:, 1:2, :]  # (2, 1, 4)  第 2 重留着，只剩 1 个
```

**别漏的动作**：写完形状，回头数一遍长度。`(3,4)[1:]` 是 `(2,4)`，不是 `(3,4)`；`[:, 1, :]` 是 `(2,4)`，不是 `(2,3,4)`。

取数不改原数组：`e[:, 1, :]` 只是这次没要 0 号位置，`e` 本身还是 `(2,3,4)`。

## 3. 广播：找共同形状

**三步**：

1. 从右往左，一位一位比
2. 短的左边补 1
3. 每一位：相等 → 过；有一个是 1 → 过（1 复制成对方那么长）；都不是 → 报错

**结果的每一位 = 比较中较大的那个。**

```python
np.ones((6, 4)) + np.ones((4,))     # ✓ (6,4)   4 对 4；行 6 对 1 → 复制
np.ones((6, 4)) + np.ones((6, 1))   # ✓ (6,4)   列 4 对 1 → 复制；行 6 对 6
np.ones((6, 4)) + np.ones((4, 1))   # ✗ 列 4 对 1 过；行 6 对 4 → 4 不是 1，不过
np.ones((6, 1)) + np.ones((2, 1))   # ✗ 列 1 对 1 过；行 6 对 2 → 不过
```

**一维数组站哪边**：

| 写法 | 补位后 | 站的方向 | 配 `(5,4)` |
| --- | --- | --- | --- |
| `(4,)` | `(1,4)` | **横着铺**，一个数管一列 | ✓ |
| `(5,1)` | `(5,1)` | **竖着排**，一个数管一行 | ✓ |
| `(5,)` | `(1,5)` | 横着，要 5 列 | ✗ 只有 4 列 |

所以：

```python
每个学生一个加分（5 个）  → reshape(5, 1)   竖着
每门课一个调整分（4 个）  → np.array([...]) 一维就行，横着
```

**标量**：一个单独的数相当于 0 维，能复制到任何形状。

```python
np.ones((100, 1)) + 1.0   # (100,1)，每个元素 +1
```

## 4. `@` 矩阵乘法

两条规矩：

1. **左边最后一个数 = 右边第一个数**，不等就报错
2. 结果形状 = **左边第一个数 + 右边第二个数**（中间那个被吃掉）

```python
np.ones((5, 3)) @ np.ones((3, 2))   # (5,2)
np.ones((100, 3)) @ np.ones((3, 1)) # (100,1)
```

**每一格怎么来的**：左边一整行 · 右边一整列，对应位置相乘再**加总**。

```python
C = [[0 1 2]      D = [[0 1]
     [3 4 5]]          [2 3]
                       [4 5]]

C @ D = [[10 13]
         [28 40]]

0*0 + 1*2 + 2*4 = 10     ← 左上角那一格
```

**“加总”就是中间那维被吃掉的原因**：相乘不改变数量，只有相加才会把 2 个数合成 1 个。一个样本因此只出一个预测值。

## 5. 线性回归的三个步骤

```python
X = np.array([[1., 2.],
              [2., 1.],
              [3., 4.],
              [4., 3.]])    # 4 个样本 × 2 个特征
w = np.array([[2.],
              [3.]])        # 2 个权重，竖着写
b = 1.0
```

### 前向：`y = X @ w + b`

```python
y = X @ w + 1.0     # (4,1) → [[9], [8], [19], [18]]
```

第一个样本 `[1,2]`：`1*2 + 2*3 = 8`，再 `+1` → **9**。`b` 只加一次，不是每个权重各加一次。

### 损失：MSE

```python
y_true = np.array([[9.], [8.], [19.], [20.]])

err = y - y_true                  # [[0], [0], [0], [-2]]
J = (err ** 2).sum() / (2 * 4)    # 4/8 = 0.5
```

三步：**相减 → 平方 → 加起来除以 2n**。`**2` 是逐元素平方，`.sum()` 是全部加起来。

### 梯度下降：`w = w - α × 梯度`

单特征、单权重的梯度：

```
梯度 = 1/n · Σ(ŷ - y) · x
```

**方向不用试数字，看误差的正负**：

- `ŷ - y` 是**正** → 猜大了 → 推 `w` 变小
- `ŷ - y` 是**负** → 猜小了 → 推 `w` 变大
- 再乘 `x` 只是票的权重：`x` 大的样本，`w` 变一点它的预测变得更多，说话更管用

那个 `1/2` 就是留给求导的：平方求导掉出一个 `2`，正好被 `1/2` 约掉，最后只剩 `(ŷ-y)·x`。

跑一遍：

```python
import numpy as np

x = np.array([1., 2.])
y = np.array([2., 4.])

w = 3.0
alpha = 0.1

for step in range(20):
    err = w * x - y
    J = (err ** 2).sum() / (2 * 2)
    grad = (err * x).sum() / 2
    w = w - alpha * grad
```

`w`：3 → 2.75 → 2.56 → … → **2.0032**；`J`：1.25 → … → **0.0000**。

**要注意的现象**：每步挪的距离越来越短（0.25 → 0.19 → …），因为越靠近谷底误差越小、梯度也越小。不会冲过头。

## 6. 公式要不要背

不用。记一句话版本：

> **梯度 = 每个样本的（预测减真实）乘上它自己的 x，加起来除以样本数。**

忘了就现场推：对 `J` 求导 → 平方掉出 2 → 被 `1/2` 约掉 → 剩 `(ŷ-y)·x`。

**注意前提**：这条只适用于「线性回归 + MSE + 单特征」。多特征时每个 `w_j` 各一条式子；带 `b` 时 `b` 那条是 `1/n·Σ(ŷ-y)`，没有 `x`；换损失就完全不同。

## 7. 这两天踩过的坑

| 坑 | 正解 |
| --- | --- |
| `(5,)` 当成竖着的一列 | 一维是**横着铺**的，要竖着写 `(5,1)` |
| 以为形状必须和原式相同 | 不必相同，`(1,4)` 配 `(5,4)` 完全正常，1 能复制 |
| `reshape(3,4)` 之后再问 shape | 答案写在参数里，这不算题（自己指出的） |
| `X @ w` 算成“每个权重各配一个 b” | 一行 × 一列 = **一个**数，先加总再加 b |
| 切片后不重数长度 | 维度留对了也要把长度重算 |
