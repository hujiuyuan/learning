## 0. 原则

- 仍然按「通用技能 → 技术实例 / 方法 → 场景 → 实践 → 项目证据」拆，不按项目拆。
- 证据分级：代码/测试/迁移/提交 > 设计/方案 > 只读/学习。计划文档不能当已落地。
- 子代理只做证据提取和草稿；主会话逐条对源文件审稿后才进 vault。
- 不一次性铺满。每阶段完成后才开下一阶段，避免一次生成几十页空卡。
- 不产生新的 `[[...]]` 红链；没有页面的名字保持纯文本。

## 3. 阶段顺序与理由

### 阶段 1：语言底座 + 请求主干（13、1–4）

先补「一个请求从进门到落库」：Java 基础/并发 → 认证 → 数据访问 → Spring/接口 → 时间序列化。

- 13 是语言底座：泛型、集合、异常、线程池、CompletableFuture、虚拟线程；先用代码里已有的用法建卡，不写教科书。
- 证据最硬：代码 + 测试 + 迁移都在。
- 和现有 MySQL 组直接相连：登录日志、租户字段、分页、软删除、时间列。
- 面试复用率最高：Spring Security、MyBatis-Plus、事务、时区都是高频题。
- 收口时节点会超过 20、出现第 2 个通用技能，触发之前推迟的 `00-图谱` 地图页和 `通用技能:` 字段，在本阶段末一次做。

### 阶段 2：数据一致性（5–7）

在多租户、事务、异步三个方向加深。

- 5 多租户依赖 1 的登录上下文和 2 的 DAO 拦截。
- 6 事务/状态依赖 2 的写路径。
- 7 异步/调度依赖 6 的事务边界和幂等。
- 这一阶段会出现跨技术对照：MySQL `tenant_id`、MyBatis 拦截器、PostgreSQL RLS 三种隔离方式。

### 阶段 3：数据架构（8–9）

从「写代码」上升到「定表和迁移」。

- 8 安全与审计：PII、密钥、审计留存。
- 9 数据建模与迁移：schema 真理源、UUIDv7、不建外键、多仓版本号。
- 这两组直接补强 MySQL 组的建表规范和迁移规范。

### 阶段 4：质量效率、前端与桌面 AI（10–12、14）

- 10 测试与质量：单测、集成测试、E2E；证据已存在，补的是方法卡。
- 11 工程效率与 AI：代码生成、Agent、CI/CD；工具链跨度大，放后面。
- 12 前端（Vue/TS）：先扫 `smart-web-*` 的提交和页面；没有个人证据就不建通用技能页，只在项目页记一笔。
- 14 桌面与本地 AI：Tauri/Rust IPC、LanceDB/RAG、keyring/Provider；NovelForge 无 git 提交，按文件证据写，不能写「已上线」。

## 4. 子代理流程

1. **证据包**（已完成）：每个候选给「技能名 / 证据等级 / 做了什么 / 路径:行号 / 场景 / 缺口」。
2. **起草**：每个通用技能一个子代理，只读源文件，按现有模板写到 `_meta/drafts/<组名>/`；每条结论必须带 `路径:行号`，写不出就不写。
3. **审稿**：主会话逐条核对；计划文档标「设计/方案」，代码/测试标「实战」；把 ADR、上游官方文档、同事提交排除出个人证据。
4. **入库**：审过的页面才移进 `20-技术能力/`；同时更新 `30-项目证据/`、README、反向链接。
5. **收口**：跑链接检查、type/证据统计、红链检查；每阶段一次。

## 5. 验收门槛

- 每个「我做过」都能指到代码、测试、迁移或提交；指不到就降级为「设计/方案」或「学习中」。
- 每个场景页至少有 1 条实践或明确写「暂无实践」。
- 不新增红链；模块名、未建卡的能力名保持纯文本。
- 不改 frontmatter 字段，除非到了阶段收口且确实有读取者。
- 项目页同步：`smart WMS`、`muou`、`e2e-hub`、`easycode-sim`、`NovelForge`。
- 每阶段结束跑一次：未解析链接数、type 分布、证据分布、孤立节点。

## 6. 已知缺口与不能吹的地方

- **授权未真正启用**：`application.yml:183` 是 `api-perm-enabled: false`，全项目零 `@PreAuthorize`；权限模型只能写「实现了一部分」。
- **`muou_arch` 的 17 个 ADR 是同事 `dodo` 写的**，只能当设计输入；个人证据在代码、迁移、`muou-server/docs` 的表设计文档。
- **计划文档复选框普遍未勾选**，但代码和测试存在；以代码/测试为准，不以 plan 状态为准。
- **e2e-hub、easycode-sim、NovelForge 没有有效 git 提交**，只能靠文件、报告、产物证明。
- **备份恢复没有实现代码**，ADR 也是 Blocked；不建「备份恢复」技能页。
- **支付真实渠道未接**，只有离线渠道和桩网关；只能写「回调幂等/渠道隔离」，不能写「支付上线」。
- **XXL-Job 只做了 PG 适配**，没有改调度算法；官方文档与个人改造要分开。
- **WMS 前端没接 i18n**，后端国际化不能写成全栈 i18n。
