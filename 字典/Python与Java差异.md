# Python / numpy 与 Java 的差异

这张表**只收两边用法或语义不一致的地方** —— 也就是「照 Java 习惯写会出错」的点。最后一列标出它有没有真的咬过你（编号对应课程档案里的错题记录）。

## 一、变量与对象

| Java 习惯 | Python 实际 | 咬过吗 |
| --- | --- | --- |
| `int a = 1;` 要写类型 | `a = 1`，不写类型；变量是**贴在对象上的名字** | |
| 基本类型按值、对象按引用 | **没有基本类型**，连 `int`/`float` 都是对象；一律「名字 → 对象」 | |
| `list.add(x)` 改原对象 | `append` / `sort` / `a[0]=` / `+=` 改原对象；**`+` / 切片 / `sorted` 造新对象** | ✓ m2 |
| `list.size()` | **`len(x)`** —— 长度是内置函数，不是对象的方法 | ✓ |
| `new ArrayList<>()` | 直接 `类名()`，**没有 `new`** | |

## 二、语法写法

| Java 习惯 | Python 实际 | 咬过吗 |
| --- | --- | --- |
| `list.get(0)` | **`a[0]`** —— `[]` 是取值 | |
| —— | **`()` 才是调用**：`np.zeros[4]` 会炸（函数不能当下标） | ✓ |
| `a[i][j]` 两层下标 | numpy 用 **`a[i, j]`** 一对方括号、逗号分隔 | ✓ |
| `for (int i=0; i<n; i++)` | `for i, x in enumerate(xs)` | |
| 方法重载 | **没有重载**，用默认参数代替 | |
| `void` | 不写 `return` 就返回 `None` | |

## 三、类

| Java 习惯 | Python 实际 | 咬过吗 |
| --- | --- | --- |
| `this` 隐式可用 | **`self` 必须显式写进参数表**，但调用时不传 | ✓ |
| 实例字段在类体里声明 | **类体只在定义类时执行一次**；写在类体里的变量 = `static` 字段，全体实例共用 | ✓ m5 |
| `this.x = v` 只写当前实例 | 给 `obj.x` 赋值永远只写**实例属性**，从不碰类属性 | ✓ m8 |
| `static` 字段 | 类属性。要每个实例各一份，必须写进 `__init__` 里的 `self.x` | ✓ m5 |

## 四、容器

| Java 习惯                     | Python 实际                                                                            | 咬过吗  |
| --------------------------- | ------------------------------------------------------------------------------------ | ---- |
| `HashMap` 不保证顺序             | **dict 3.7+ 保证插入顺序** —— 对应 Java 的 `LinkedHashMap`                                    |      |
| `map.get(k)` 取不到返回 null     | **`d[k]` 取不到抛 `KeyError`**；`d.get(k)` 返回 `None`；`d.get(k, default)` = `getOrDefault` | ✓ m7 |
| key 只要有 `hashCode`/`equals` | key 必须 **hashable**（不可变）；`list`、`dict` 不能当 key                                       | ✓ m7 |
| `containsKey(k)`            | `k in d`                                                                             |      |
| `entrySet()`                | `d.items()`                                                                          |      |

## 五、资源与异常

| Java 习惯 | Python 实际 | 咬过吗 |
| --- | --- | --- |
| `try (var f = ...) { }` | **`with open(...) as f:`** —— 是 `try/finally` 的语法糖 | ✓ m13 m14 |
| —— | 不用 `with` 就必须自己 `close()`；靠 GC 关文件**没有语言保证** | ✓ m13 |
| —— | 跳出 `with` 块的方式有正常结束、抛异常、`return`、`break`，**全都会触发关闭** | ✓ m14 |

## 六、numpy 独有（Java 没有对应物）

| 点 | 说明 | 咬过吗 |
| --- | --- | --- |
| `*` 的意思 | 列表 `*` 是重复；**数组 `*` 是逐元素乘** | |
| 形状是一个元组 | `np.zeros((3, 4))` —— 不是 `np.zeros(3, 4)`（后者把 `4` 当成 `dtype`） | ✓ m15 |
| reshape 的括号 | `b.reshape(3, 4)` 和 `b.reshape((3, 4))` **两种都行** | |
| **整数下标 vs 切片** | **整数 = 消掉那一维（降维）；切片 = 保留那一维（保维，哪怕长度为 1）** | 正在学 |
| 切片边界 | 左闭右开（和 Java 的 `subList` 一致，但 Java 数组没有切片） | ✓ m3 |
| 内存布局 | 数组是一块连续内存；列表是一堆指针 | |
| 运算都造新对象 | `b = a * 2` 之后 `a` 不变，和列表规则一致 | |

## 七、还没碰到、但迟早会咬你的

- **`is` 是「同一个对象」，`==` 是「值相等」** —— 别把 `is` 当 `==` 用
- **函数默认参数写成可变对象**（`def f(x=[])`）会跨调用共享 —— 和你已经踩过的 m5 是同一个坑，只是换了位置
- **浮点比较用 `math.isclose`**：`0.1 + 0.2 != 0.3`（是精度问题，不是「数字不能比较」）✓ m1
- **`+=` 对列表是改原对象**（`a += [3]` 会让别名也变），跟 `a = a + [3]` 不一样 ✓ m2
