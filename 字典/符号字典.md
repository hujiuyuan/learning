## 线性回归这一阶段

| 符号 | 含义 |
| --- | --- |
| `X` | 输入矩阵，`(样本数, 特征数)` |
| `w` | 权重向量，`(特征数, 1)` |
| `b` | 偏置，标量 |
| `ŷ` | 预测值，`(样本数, 1)` |
| `err` | `ŷ - y`，误差 |
| `J` | 损失，一个数；越小越好 |
| `dJ/dw` | `J` 对 `w` 的导数（梯度） |
| `dJ/db` | `J` 对 `b` 的导数 |
| `dW` | 多特征时 `w` 的梯度，形状同 `w` |
| `db` | 多特征时 `b` 的梯度，标量 |
| `lr` / `α` | 学习率，每步走多大 |

`dJ/dw` 是整体记号，读作「`J` 对 `w` 的导数」，不是 `d×J÷d×w`。

字体规则（什么时候加粗、什么时候用花体）见 [[字体用法差异]]。
