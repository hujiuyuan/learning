
| 公式                                               | 含义                                                                                                    |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| $\hat y = wx + b$                                | 一元线性回归公式;<br>只有一个特征x，w，b是标量，预测一个值                                                                     |
| $\hat y = w_1x_1 + w_2x_2 + \cdots + w_dx_d + b$ | 多特征线性回归公式;<br>同一个样本有d个特征$x_1 \cdots x_d$,每个特征一个权重$w_j$                                                |
| $\hat y = \mathbf w^T \mathbf x + b$             | 多特征线性回归公式（另一种写法）;<br>$\mathbf w^Tx = \sum^d_{j=1} w_jx_j = w_1x_1 + w_2x_2 + \cdots + w_dx_d + b$<br> |
| $\hat y_i = wx_i + b$                            | 第i个样本的预测，下标i通常意思是样本的编号                                                                                |
