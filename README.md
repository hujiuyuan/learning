# learning

## 目标

**第一关（终点）**：不使用任何自动求导库（无 PyTorch／TensorFlow／autograd），纯 numpy 手写一个字符级语言模型 ——
(a) 前向和反向都自己实现，能在纸上推出任意一个权重梯度的来历；
(b) 在莎士比亚文本上训练后，采样输出有可辨认的英文词形、空格和标点，不是乱码；
(c) 能解释损失为什么下降、学习率取太大或太小分别会发生什么。

**第二关（加分）**：在同一套手写框架里加上 attention，做出字符级 Transformer。
