# 本地优先

技能点：[[Tauri与Rust IPC]] · 方法：本地优先数据布局（待建） · 通用技能：[[桌面与本地AI]]

**什么时候会遇到**：做个人创作/知识管理/离线工具，要求「数据归用户、断网能用、密钥不外泄」，但又要接云端模型做可选增强。

## 判断顺序

1. **先分数据**：哪些是用户资产（稿件、真相文件、导出物），哪些是缓存（向量索引、缩略图），哪些是秘密（API Key）。
2. **再分存储**：结构化资产进 SQLite（实现细节见 [[SQLite]]）；向量进嵌入式库；秘密进系统凭据库；导出物进普通文件。
3. **再问出站**：哪些请求允许离开本机？请求里是否带正文？用户能否选择只用本地模型？
4. **再问可恢复**：索引删了能不能重建？数据库升级能不能回退？误删能不能撤销？
5. **最后问离线**：没有 Key、没有网络时，哪些功能必须仍可用？测试是否默认不联网？

## 手段

- **单根目录**：db + WAL + lancedb + exports + snapshots 全在一个目录，备份 = 复制目录。证据：`novelforge/src-tauri/src/state.rs:1-17`。
- **SQLite WAL + 版本化迁移**：迁移只追加、不改历史；拒绝打开比自己新的数据库。证据：`novelforge/src-tauri/src/db.rs:1-13`、`:24`、`:189`、`:214-232`。
- **文本镜像 + 可重建索引**：SQLite 的 `rag_chunks` 是镜像，LanceDB 只是缓存；镜像空了能回扫 chapters。证据：`novelforge/src-tauri/src/commands/memory.rs:1-10`、`:138-149`。
- **密钥进系统库**：默认 keychain，开发可切 0600 文件；数据库只存标记。证据：`novelforge/src-tauri/src/keyring.rs:31-57`、`novelforge/src-tauri/src/commands/agent.rs:356-381`。
- **破坏性操作先快照**：删除项目、清空内容、重导、重跑设定师/大纲师前写 JSON 快照，每项目保留 5 份。证据：`novelforge/src-tauri/src/snapshot.rs:1-10`、`:28`、`:82`。
- **数据目录可覆盖**：`NOVELFORGE_DATA_DIR` 指向隔离目录，测试/冒烟不会迁移真实库。证据：`novelforge/src-tauri/src/lib.rs:92-102`、`novelforge/CLAUDE.md:87`。
- **离线优先的测试**：集成测试用内存库 + mock provider，无 Key、无网络。证据：`novelforge/src-tauri/src/integration_tests.rs:1-8`。
- **导出物落本地**：Markdown/DOCX/EPUB 写到数据目录下的 exports。证据：`novelforge/src-tauri/src/state.rs:104-117`。

## 反例 / 边界

- **本地优先 ≠ 不出网**：LLM 请求必然出站；远端嵌入也会把分块文本发出去。用户要能选择 Ollama/本地嵌入。
- **本地文件 ≠ 备份**：单机单目录，没有云同步、自动备份、异机恢复演练；磁盘坏了就是丢了。
- **「密钥不落盘」只对 keychain 成立**：`file` 后端就是明文 JSON（0600），是开发便利，不是安全等价物。
- **快照不覆盖向量索引**：索引按设计可丢弃，所以快照只存稿件与真相数据（`novelforge/src-tauri/src/snapshot.rs:6-9`）。
- **没有数据库加密**：SQLite 明文；没做 SQLCipher。
- **没做多设备冲突合并**：同一份数据放两台机器上同时改，没有版本向量或 CRDT。
- **签名状态会影响本地体验**：macOS ad-hoc 签名每次重建都让钥匙串重新授权，才需要 file 后端兜底（`novelforge/src-tauri/src/keyring.rs:31-37`）。

## 现在的规矩

1. 新数据先归类：资产 / 缓存 / 秘密，再决定放哪。
2. 秘密只进系统凭据库或 0600 文件，绝不进 SQLite、日志、错误信息、前端状态。
3. 索引一律当缓存：必须能从文本重建，且记录 embedder 身份。
4. 破坏性操作先快照，快照保留有限份数并给出恢复入口。
5. 离线路径必须有自动化测试；测试默认不联网、不需要 Key。
6. 数据目录写进文档，备份说明是「复制哪个文件夹」，不是「导出什么格式」。
