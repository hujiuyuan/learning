# 技术栈索引

按层列出 2026-05 至 2026-10 实际接触过的技术，解决「技能地图只有组名、看不到具体技术」的问题。按阅读目的找内容，走 [[四层读法]] 的四个入口；本页只回答「有没有页、是什么状态」。技术背后的机制、成立条件和失效模式见 [[理论基础]]。状态只有四种：

- **有独立页**：有单独的技术页，能点进去看「我做过什么 + 边界」。
- **组内页**：没有单独技术页，内容并在一页里（例如 TypeScript + Vite）。
- **待建**：用过或接触过，但还没建独立页；正文里不写成「已掌握」。
- **未使用**：没有项目证据，不建实战卡。
